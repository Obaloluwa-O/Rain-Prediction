Just wrapped up a hands-on project where I built a Rainfall Prediction Classifier using real weather data from the Australian Bureau of Meteorology 🌧️.
I explored the data, engineered seasonal and location-based features, and built end-to-end machine learning pipelines. Using GridSearchCV for hyperparameter tuning, I compared Random Forest and Logistic Regression models.
Key outcomes:
•	Achieved ~84% accuracy in predicting rainfall in the Melbourne area
•	Random Forest performed slightly better overall, especially on recall for "No Rain" days
•	Logistic Regression offered simpler interpretability with competitive accuracy
Recommendation:
For operational use, Random Forest is the stronger candidate due to its higher reliability, but combining it with simpler models like Logistic Regression could offer a balance between accuracy and explainability.
This project sharpened my skills in feature engineering, pipeline design, cross-validation, and model evaluation—key steps in building deployable AI solutions.
